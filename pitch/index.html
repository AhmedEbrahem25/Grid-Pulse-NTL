Why the grid is blind

Cable and transformer losses are real, and they rise with heat and load. A fixed loss threshold cries wolf all summer — so operators mute it, and real theft hides inside the noise.

A battery of hair-dryers, a brick-kiln, a workshop hooked past the meter — the transformer feels it as “more loss.” Without context, every hot afternoon looks like theft, and every theft looks like a hot afternoon.

04

From breadboard to busbar

A real edge node, not a slide. Current transformer → signal conditioning → ESP32 → a strict, signed telemetry contract the backend enforces on every packet.

Distribution kiosk (RMU) · Kafr El-Sheikh
This is the real target. Inside the kiosk, three Rogowski coils wrap the low-voltage busbars — one per phase — feeding an IP65 edge node. The 11 kV side is never touched and no feeder is disconnected. See how it deploys →
Edge node — today

ESP32 + split-core CT

  • SCT-013-000 clamp, 100 A : 50 mA, non-invasive
  • 33 Ω burden + 1.65 V bias into the ADC — measured, not guessed
  • EmonLib RMS, calibration ≈ 60.6, NTP-timestamped
  • Posts contract-valid JSON over Wi-Fi with a bearer token
Production — the roadmap

Kiosk-grade sensing

  • Rogowski coils on the LV busbar, IP65 enclosure
  • LoRaWAN backhaul — no field Wi-Fi needed
  • TinyML on-device: transmit only when theft is found (−99% bandwidth)
  • Theft-location triangulation across feeders
Backend

FastAPI · Redis · Celery

  • Strict JSON-Schema contract — malformed packets get 422, bad tokens 401
  • Inline or worker detection — same verdict, demo-safe either way
  • Live map + verdicts over WebSocket, 2 s polling fallback
